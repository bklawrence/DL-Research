# Optional public state downloads

Only place **public, school-aggregate** state files here. Never upload identifiable student data or restricted data. To use a file on GitHub, commit it under a state-specific folder like `incoming/WI/2025_access_public.xlsx`. The collector reads it on the next run.

For large files or frequently changing sources, prefer setting a trusted state-maintained direct HTTPS link in `collect_access.py` rather than checking a large binary into GitHub.
